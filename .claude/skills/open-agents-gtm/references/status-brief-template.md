# GTM Status Brief Template

Use this compact shape for repo-native GTM status answers.

## Confirmed

- Current implemented capability or merged PR state.
- Relevant API, module, route, issue, or doc evidence.

## Source Gaps

- Missing runtime/API/database/GitHub evidence.
- Unbuilt planned surface.
- Auth or permission blocker.

## Recommended Next Action

- One next action, tied to evidence.
- Name whether it is read-only, local draft/proposal, implementation work, or
  approval-required mutation.

## Evidence Used

- GitHub issue/PR numbers.
- Local files inspected.
- Commands or route checks used.

Avoid long strategy prose when the user asked for status. Be clear about what
is implemented versus planned.

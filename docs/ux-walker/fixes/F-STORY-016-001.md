# F-STORY-016-001 Fix Report

## What Was Wrong

The loop template gallery rendered repeated `Use this template` buttons. The visible text was fine for sighted users because each button sat inside a card, but assistive technologies saw several identical actions with no template context.

## What Changed

- `apps/web/app/loops/loop-create-experience.tsx`
  - Added `getTemplateActionLabel`.
  - Added target-specific `aria-label` values to template action buttons while leaving the compact visible label unchanged.
- `apps/web/app/loops/loop-create-experience.test.tsx`
  - Added coverage for named template action labels.

## Verification

- Browser smoke: refreshed `/loops/new` and confirmed template actions expose labels such as `Use Review to issues template` and `Use Backlog -> PR template`.
- Tests: `bun test apps/web/app/loops/loop-create-experience.test.tsx`.
- Gate: `bun --bun run check`.

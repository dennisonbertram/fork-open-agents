# F-STORY-010-001 Fix Report

## What Was Wrong

The Cursor Composer preset existed, but only after selecting the OpenAI-compatible provider. During the UX walk, this made the intended Cursor path dependent on the provider dropdown before the user could see the shortcut.

## What Changed

- `apps/web/app/settings/inference-profiles-section.tsx`
  - Added `createCursorInferenceProfileDraft`.
  - Moved the Cursor Composer preset block so it is visible immediately in the New/Edit Inference Profile dialog.
  - The shortcut now sets provider to `openai-compatible`, preserves an existing custom name, fills `http://127.0.0.1:8787/v1`, and fills `composer-2.5` / `composer-2.5-fast`.
- `apps/web/app/settings/inference-profiles-section.test.ts`
  - Added focused regression coverage for the Cursor draft helper.

## Verification

- `bun --bun run check`

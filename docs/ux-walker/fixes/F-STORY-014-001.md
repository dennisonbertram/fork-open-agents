# F-STORY-014-001 Fix Report

## What Was Wrong

Skill cards showed edit and delete as hover-only icon buttons without accessible names. The enable switch used a generic `Disable skill` / `Enable skill` label, so assistive technology could not identify which slash skill the control affected.

## What Changed

- `apps/web/app/settings/skills/skills-section.tsx`
  - Added `Edit /{skill}` and `Delete /{skill}` labels.
  - Added target-specific switch labels: `Disable /{skill}` and `Enable /{skill}`.
  - Added `getSkillActionLabels` with regression coverage.

## Verification

- Browser smoke: created a temporary skill and confirmed the card exposed `Edit /bad-name`, `Delete /bad-name`, and `Disable /bad-name`.
- Tests: `bun test apps/web/app/settings/skills/skills-section.test.ts`.

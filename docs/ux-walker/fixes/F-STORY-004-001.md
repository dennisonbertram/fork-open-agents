# F-STORY-004-001 Fix Report

## What Was Wrong

When Vercel project lookup failed in the New Session repo path, the compact error row was a button that contained a nested Retry button. React logged an invalid HTML error and the control had poor keyboard semantics.

## What Changed

- `apps/web/components/session-starter-vercel-sync-section.tsx`
  - Added an optional compact-row action slot.
  - Rendered the compact row as a non-button container with separate sibling buttons for row expansion and Retry.
- `apps/web/components/session-starter-vercel-sync-section.test.tsx`
  - Added regression coverage to ensure the compact Retry control is not nested inside the row button.

## Verification

- `bun test apps/web/components/session-starter-vercel-sync-section.test.tsx apps/web/components/new-session-dialog.test.tsx apps/web/app/settings/inference-profiles-section.test.ts apps/web/lib/inference/profile-models.test.ts apps/web/lib/model-options.test.ts apps/web/lib/inference/model-routing.test.ts`
- Browser smoke: opened `/sessions`, opened New Session, selected Connect a repo, confirmed the Vercel lookup error row renders “Could not load Vercel projects” and “Retry” as separate sibling buttons, started a repo session, and saw zero browser console errors.

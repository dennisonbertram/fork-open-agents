# F-STORY-015-001 Fix Report

## What Was Wrong

The background agents page contained repeated row actions with identical labels. Screen readers could not distinguish which agent `Edit`, `Test`, `Repo`, or `Delete agent` referred to, and run-history `Output` / `Details` links had the same problem.

## What Changed

- `apps/web/app/settings/background-agents-section.tsx`
  - Added target-specific labels for agent edit, test, repo, delete, and webhook-copy controls.
  - Added target-specific labels for run output and details links.
  - Added a label to the create form's enabled switch.
  - Extracted small row components and label helpers with regression coverage.

## Verification

- Browser smoke: refreshed `/settings/background-agents` and confirmed labels such as `Test background agent Live Proof Background Agent`, `Copy webhook URL for Live Proof Background Agent`, and `Open details for background run dennisonbertram/synthetix ...`.
- Tests: `bun test apps/web/app/settings/background-agents-section.test.ts apps/web/app/settings/background-agents-section.test.tsx`.

# F-STORY-005-001 Fix Report

## What Was Wrong

The chat header knew the connected repo was `dennisonbertram/synthetix`, but the agent prompt only exposed the sandbox working directory and current branch. When asked to confirm the repo and branch, the assistant inferred the repo name from the sandbox directory and answered `sandbox`.

## What Changed

- `packages/agent/system-prompt.ts`
  - Added optional `repoOwner` and `repoName` prompt inputs.
  - Added an Environment line for `Connected repository: owner/repo`.
  - Explicitly instructs the agent not to infer the repo name from the sandbox working directory.
- `packages/agent/open-agent.ts`
  - Added repo metadata to `AgentSandboxContext`.
  - Passes repo metadata into `buildSystemPrompt`.
- `apps/web/app/workflows/chat.ts`
  - Passes `runtime.repoOwner` and `runtime.repoName` into the agent sandbox context.
- `packages/agent/open-agent.test.ts`
  - Added regression coverage for connected repo prompt context.

# F-STORY-003-001 Fix Report

## What Was Wrong

The sessions index has a “New Session” button, but the opened dialog was titled “New chat” for assistive tech and browser automation. That was confusing because the dialog supports both quick chat and repo-backed session creation.

## What Changed

- `apps/web/components/new-session-dialog.tsx`
  - Added `NEW_SESSION_DIALOG_TITLE`.
  - Changed the sr-only dialog title to `New session`.
- `apps/web/components/new-session-dialog.test.tsx`
  - Added a regression test for the dialog title constant.

## Verification

- Browser smoke: opened `/sessions`, clicked “New Session”, confirmed the dialog is now announced as “New session”, and saw no console errors.

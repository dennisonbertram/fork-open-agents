# F-STORY-012-001 Fix Report

## What Was Wrong

The full Composio settings page showed a saved Email profile's Gmail toolkit as `not connected`, but the compact chat tool selector still showed the saved Email profile as selectable. That made it possible to choose a tool profile that could not actually run.

## What Changed

- `apps/web/lib/composio/profile-option-availability.ts`
  - Added a shared helper that marks saved profile options unavailable when they include a required-auth toolkit with no connected account.
- `apps/web/components/composio-tool-selector-compact.tsx`
  - Loaded toolkit catalog and connected-account state alongside saved Composio settings.
  - Applied the availability helper before rendering saved profile options.
- `apps/web/lib/db/composio.ts`
  - Added a server-side disconnected-tool reason for profiles that persist auth config ids but no connected account ids.

## Verification

- Browser smoke: opened the Composio settings page, confirmed Gmail was shown as `not connected` inside the Email profile, then opened the chat tool selector and confirmed Email was disabled with `Tool not connected: gmail.`
- Tests: `bun test apps/web/lib/composio/profile-option-availability.test.ts apps/web/lib/db/composio.test.ts`.

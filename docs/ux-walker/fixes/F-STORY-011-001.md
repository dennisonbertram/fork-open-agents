# F-STORY-011-001 Fix Report

## What Was Wrong

User-created model variant cards showed edit and delete as icon-only buttons. Tooltips described the controls visually, but the buttons themselves had no accessible names in the interactive tree.

## What Changed

- `apps/web/app/settings/model-variants-section.tsx`
  - Added `aria-label={`Edit ${variant.name}`}` to the edit action.
  - Added `aria-label={`Delete ${variant.name}`}` to the delete action.

## Verification

- Browser smoke: created a temporary model variant, confirmed the action labels appeared as `Edit UX Walker Temp Variant` and `Delete UX Walker Temp Variant`, edited the variant, and confirmed the labels updated with the edited name.
- Cleanup: removed the temporary variant from persisted preferences and verified `remaining: 0`.

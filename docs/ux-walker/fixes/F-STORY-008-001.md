# F-STORY-008-001 Fix Report

## What Was Wrong

The PR panel could create a real GitHub pull request while the compact form only showed `Create Pull Request`, `PR options`, and `Edit title & description`. Because the title can be blank and auto-generated at submission time, the user did not get clear pre-action copy about the branch, base branch, or automatic generation behavior.

## What Changed

- `apps/web/app/sessions/[sessionId]/chats/[chatId]/git-panel-copy.ts`
  - Added a pure helper for the PR creation notice copy.
- `apps/web/app/sessions/[sessionId]/chats/[chatId]/git-panel.tsx`
  - Shows the PR creation notice directly above `Create Pull Request`.
  - Names the source branch, base branch, and whether title/body will be generated first.
  - Added accessible labels to the commit-message and PR-details generation icon buttons.
- `apps/web/app/sessions/[sessionId]/chats/[chatId]/git-panel.test.ts`
  - Added focused regression coverage for the PR creation notice helper.

## Verification

- `bun test 'apps/web/app/sessions/[sessionId]/chats/[chatId]/git-panel.test.ts'`
- Browser smoke: opened a repo chat, opened Changes, confirmed the no-uncommitted-changes disabled commit state, opened PR, expanded PR details, opened PR options, and verified the new PR consequence copy after the hot update.

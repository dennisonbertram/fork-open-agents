## Why this matters

Every typed REST call the iOS app ever makes flows through `ios/Packages/OpenAgentsAPI` — the checked-in Swift client generated from `apps/web/openapi.json`. This issue creates that package: the vendored spec, the generator config with the include-filter, the regeneration and drift scripts, committed generated sources pinned to swift-openapi-generator 1.12.2, the client factory with the fractional-seconds date transcoder, and a smoke test that proves a real fixture decodes through generated types. Without it, M3+ networking work has no typed surface, and without the drift scripts the generated client can silently diverge from the server contract — the exact failure mode the web side already guards with `apps/web/scripts/check-openapi.ts`. Checked-in generation (no build plugin) gives deterministic builds, reviewable diffs, and no codegen at app-build time.

## User/operator path protected

P10 — the contract-sync path for every iOS contributor and CI: regeneration from the committed spec is a no-op (`./ios/Scripts/check-api-drift.sh` exits 0), and a change to `apps/web/openapi.json` without regenerating the Swift client turns the drift script red with an actionable message. Secondary protected path: an iOS developer on a fresh checkout runs one script and gets a compiling, tested, typed API client.

## Behavior contract

- Given a clean checkout where M1-01 (OpenAPI Batch A hygiene) and M2-01 (`ios/` scaffold) are merged, when a developer runs `./ios/Scripts/generate-api.sh`, then `ios/Packages/OpenAgentsAPI/Sources/OpenAgentsAPI/openapi.json` is a byte-identical copy of `apps/web/openapi.json`, `openapi-generator-config.yaml` lists every spec `operationId` except `postChat`, `resumeChatStream`, `stopChat`, `getChat` under `filter.operations`, and `Sources/OpenAgentsAPI/GeneratedSources/Types.swift` + `Client.swift` are regenerated by swift-openapi-generator 1.12.2.
- Given the committed state of this PR, when CI or a developer runs `./ios/Scripts/check-api-drift.sh`, then regeneration produces zero diff under `ios/Packages/OpenAgentsAPI` and the script exits 0 printing `✓ ios/Packages/OpenAgentsAPI is in sync with apps/web/openapi.json`.
- Given any edit to `apps/web/openapi.json` (for example a description string change) without regenerating, when `./ios/Scripts/check-api-drift.sh` runs, then it exits 1 and prints `Generated OpenAPI client is out of date with apps/web/openapi.json.` and `Run: ./ios/Scripts/generate-api.sh and commit the diff.` to stderr.
- Given a future spec that documents the four hand-rolled chat operations (a later M1 batch adds `postChat`, `resumeChatStream`, `stopChat`, `getChat` for discoverability), when `./ios/Scripts/generate-api.sh` runs, then no Swift symbol is generated for those four operations, and `check-api-drift.sh` fails with `Hand-rolled chat operations leaked into the generated client; fix the filter.` if any of them appear in `GeneratedSources/Client.swift`.
- Given the generated client built by `OpenAgentsAPIFactory.makeClient(...)` (which pins `Configuration(dateTranscoder: .iso8601WithFractionalSeconds)`), when the smoke test feeds a `listSkills` 200 fixture containing `"createdAt": "2026-02-02T02:40:00.123Z"` through a stub transport, then decoding succeeds and the `Date` equals epoch `1770000000.123` within 0.5 ms.
- Given the same fixture decoded through a client configured with the default `.iso8601` transcoder (no fractional seconds), when `listSkills` output is read, then decoding throws — proving the factory configuration is load-bearing, not decorative.
- Given `Package.resolved` is missing or deleted, when `generate-api.sh` runs (it passes `--force-resolved-versions`), then SwiftPM fails loudly instead of silently resolving a different generator version; the fix is `swift package --package-path ios/Packages/OpenAgentsAPI resolve` and committing the lockfile.

## Product and design spec

Developer-facing tooling; no end-user UI. Entry points are two executable scripts and one Bun script:

- `./ios/Scripts/generate-api.sh` — regenerate everything (the "fix it" command).
- `./ios/Scripts/check-api-drift.sh` — verify-only gate (the "is it broken" command); also invoked by `ios/Scripts/ci.sh` once M2-03 lands.
- `ios/Scripts/update-openapi-filter.ts` — internal; invoked by `generate-api.sh`, runnable standalone via `bun run ios/Scripts/update-openapi-filter.ts`.

States and copy (exact strings, they are the UX):

- Sync: `✓ ios/Packages/OpenAgentsAPI is in sync with apps/web/openapi.json` (stdout, exit 0).
- Drift: `Generated OpenAPI client is out of date with apps/web/openapi.json.` + `Run: ./ios/Scripts/generate-api.sh and commit the diff.` (stderr, exit 1).
- Filter leak: `Hand-rolled chat operations leaked into the generated client; fix the filter.` (stderr, exit 1).
- Filter summary: `openapi-filter: included=<n> excluded=<m> (<comma-separated excluded ids or "none">)` (stdout from the Bun script).

Permissions: both `.sh` scripts are committed with `chmod +x`. No network access is required at generation time beyond SwiftPM resolving pinned dependencies (cached after first run). Error behavior: all scripts use `set -euo pipefail`; any tool failure aborts with a non-zero exit. Accessibility/empty/loading states: not applicable (CLI).

`ios/Scripts/check-api-drift.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
ROOT="$(cd "${SCRIPT_DIR}/../.." && pwd)"

"${SCRIPT_DIR}/generate-api.sh"
if ! git -C "${ROOT}" diff --exit-code -- ios/Packages/OpenAgentsAPI; then
  echo "" >&2
  echo "Generated OpenAPI client is out of date with apps/web/openapi.json." >&2
  echo "Run: ./ios/Scripts/generate-api.sh and commit the diff." >&2
  exit 1
fi
if grep -E "func (postChat|resumeChatStream|stopChat|getChat)\b" \
    "${ROOT}/ios/Packages/OpenAgentsAPI/Sources/OpenAgentsAPI/GeneratedSources/Client.swift" >/dev/null 2>&1; then
  echo "Hand-rolled chat operations leaked into the generated client; fix the filter." >&2
  exit 1
fi
echo "✓ ios/Packages/OpenAgentsAPI is in sync with apps/web/openapi.json"
```

`ios/Scripts/update-openapi-filter.ts` (the swift-openapi-generator `filter` key is an include-list, so the script computes "everything except the four hand-rolled chat operations" and owns the whole config file so the list can never drift from the spec):

```ts
// Rewrites ios/Packages/OpenAgentsAPI/Sources/OpenAgentsAPI/openapi-generator-config.yaml
// from apps/web/openapi.json. Run via: bun run ios/Scripts/update-openapi-filter.ts
import { readFileSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const HAND_ROLLED = ["postChat", "resumeChatStream", "stopChat", "getChat"];
const repoRoot = join(import.meta.dir, "..", "..");
const spec = JSON.parse(
  readFileSync(join(repoRoot, "apps", "web", "openapi.json"), "utf8"),
) as { paths: Record<string, Record<string, unknown>> };

const operationIds = new Set<string>();
for (const methods of Object.values(spec.paths)) {
  for (const op of Object.values(methods)) {
    if (
      op &&
      typeof op === "object" &&
      "operationId" in op &&
      typeof op.operationId === "string"
    ) {
      operationIds.add(op.operationId);
    }
  }
}
const included = [...operationIds]
  .filter((id) => !HAND_ROLLED.includes(id))
  .sort();
const excluded = [...operationIds]
  .filter((id) => HAND_ROLLED.includes(id))
  .sort();

const config = `# Generated by ios/Scripts/update-openapi-filter.ts — do not edit by hand.
generate:
  - types
  - client
accessModifier: public
namingStrategy: idiomatic
additionalFileComments:
  - "swift-format-ignore-file"
filter:
  operations:
${included.map((id) => `    - ${id}`).join("\n")}
`;
writeFileSync(
  join(
    repoRoot,
    "ios",
    "Packages",
    "OpenAgentsAPI",
    "Sources",
    "OpenAgentsAPI",
    "openapi-generator-config.yaml",
  ),
  config,
);
console.log(
  `openapi-filter: included=${included.length} excluded=${excluded.length} (${excluded.join(", ") || "none"})`,
);
```

`OpenAgentsAPI.swift` (factory; the `transport:` overload exists so tests can inject a stub while production code uses the `session:` overload — both funnel through one `Configuration`):

```swift
import Foundation
import OpenAPIRuntime
import OpenAPIURLSession

public enum OpenAgentsAPIFactory {
  public static func makeClient(
    serverURL: URL,
    transport: any ClientTransport,
    middlewares: [any ClientMiddleware] = []
  ) -> Client {
    Client(
      serverURL: serverURL,
      configuration: Configuration(dateTranscoder: .iso8601WithFractionalSeconds),
      transport: transport,
      middlewares: middlewares
    )
  }

  public static func makeClient(
    serverURL: URL,
    session: URLSession,
    middlewares: [any ClientMiddleware]
  ) -> Client {
    makeClient(
      serverURL: serverURL,
      transport: URLSessionTransport(configuration: .init(session: session)),
      middlewares: middlewares
    )
  }
}
```

## Observability and user feedback

This package ships no runtime logger by design (generated code plus a pure factory; request/response logging via the `api` OSLog category — subsystem `com.openagents.ios`, events `api_request_started`/`api_request_finished`/`api_decode_failed` per `docs/plans/ios-app/07-observability.md` section 4.2 — is `APIClient`/M3 scope). Observability for this slice is script-and-CI-level, module name `openapi-drift`:

- `ios/Scripts/check-api-drift.sh` success line (info-equivalent, stdout): `✓ ios/Packages/OpenAgentsAPI is in sync with apps/web/openapi.json`.
- Drift failure (error-equivalent, stderr, exit 1) — typed by its stable first line, errorKind `client_drift`: `Generated OpenAPI client is out of date with apps/web/openapi.json.`
- Filter leak failure (error-equivalent, stderr, exit 1), errorKind `filter_leak`: `Hand-rolled chat operations leaked into the generated client; fix the filter.`
- `ios/Scripts/update-openapi-filter.ts` summary (info, stdout): `openapi-filter: included=<count> excluded=<count> (<ids|none>)` with fields `included`, `excluded`.
- Correlation: there are no requestId/sessionId/chatId at codegen time; the correlation key for an incident is the pair of git SHAs of `apps/web/openapi.json` and `ios/Packages/OpenAgentsAPI/Sources/OpenAgentsAPI/openapi.json` (`git log -1 --format=%h -- <path>` each).
- Redaction: `openapi.json` is a public contract and contains no secrets; the smoke fixture is hand-authored, never recorded from a live backend. Guard (must return nothing, mirroring `docs/plans/ios-app/06-testing-strategy.md` fixture sanitization): `grep -rEn "ghs_|gho_|vc_|Bearer " ios/Packages/OpenAgentsAPI/Tests/`.
- Debug recipes an operator can run during a red gate:
  - `./ios/Scripts/check-api-drift.sh; echo "exit=$?"` — reproduce the gate locally.
  - `git -C . diff --stat -- ios/Packages/OpenAgentsAPI` — see exactly which generated files moved.
  - `diff <(grep -o '"operationId": "[^"]*"' apps/web/openapi.json | sort) <(grep -o '"operationId": "[^"]*"' ios/Packages/OpenAgentsAPI/Sources/OpenAgentsAPI/openapi.json | sort)` — spot the operation that changed.

## Regression harness plan

- Continuous (this PR): the two smoke tests in `GeneratedClientSmokeTests.swift` run on every `swift test --package-path ios/Packages/OpenAgentsAPI`; they fail if the generated `Client`/`Components.Schemas.UserSkill` surface or the date transcoder regresses. Fail-before/pass-after: observed failing (build error) before generation, passing after.

## Regression risks and concerns

- Generator nondeterminism would make the drift gate flap. Mitigation: the generator is pinned (`exact: "1.12.2"` + committed `Package.resolved` + `--force-resolved-versions`); the include-list is sorted; the config file is fully script-generated. Any gate flap without a spec change is a bug in this slice.
- `git diff --exit-code` does not flag brand-new untracked files. This only matters on first generation (covered by the red/green flow); after this PR all generated files are tracked, and the 1.12.x generator emits a fixed file set (`Types.swift`, `Client.swift`).
- A backend PR that edits `apps/web/openapi.json` will, once M2-03 lands, go red on `ios-api-drift` until someone runs `./ios/Scripts/generate-api.sh` and commits — intentional (same philosophy as `openapi:check`), but it must be documented in the PR body so web contributors are not surprised; M2-03's `docs/process/ios-gate.md` owns the durable write-up.
- The `filter.operations` include-list semantics: if the Bun script silently produced an empty list, the generator would emit an empty client and the smoke test would fail to compile — acceptable loud failure. If the script were skipped, a stale list would drop newly added operations; the drift script reruns it on every check, so the config cannot go stale while the gate runs.
- `namingStrategy: idiomatic` fixes generated Swift names; changing it later regenerates the entire client surface and breaks `APIClient` callers. Treat the config keys (other than `filter.operations`) as frozen API.
- Swift 6.2 strict concurrency: generated code and `OpenAgentsAPIFactory` must compile under the nonisolated-default template settings. If the generated code warns/errors under a template flag, record the exact diagnostic in `docs/agents/lessons-learned.md` and adjust only the package's `swiftSettings` with a comment — never hand-edit generated sources.
- The new `.ts` file under `ios/Scripts/` is the first TypeScript outside `apps/`/`packages/`; if root tooling (`bun run ci`) treats it unexpectedly (lint scope, test discovery), fix formatting rather than adding ignores — `ios/**` ignore policy belongs to M2-03.

## Environment notes for future walkers

1. Prefer local app + test-auth over Production. Never set `OPEN_AGENTS_ENABLE_TEST_AUTH` on Production.
2. Seed `users` + `accounts(provider=github)` + `github_installations` for the test user, then **mock** `/api/github/connection-status` (or use a real token) — otherwise `GitHubReconnectGate` blocks the whole app.
3. Confirm DB host before writes: `grep '^POSTGRES_URL=' apps/web/.env.local | grep -o 'ep-[a-z0-9-]*' | head -1` — stop on `ep-soft-silence`.
4. This walk used a fresh local Postgres; Neon `ep-old-union` was unavailable (no Vercel CLI auth in the cloud VM).
